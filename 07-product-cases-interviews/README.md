## 解题约定

每个案例采用：**定义问题 → 统一口径 → 结构拆解 → 验证原因 → 产品措施 → 实验与护栏**。这是一种判断框架，不要求背诵固定套话；遇到安全与合规风险，应先遵守约束，而不是把其作为可被利润抵消的损失。

所有案例数值虚构；不能将模拟项目当成真实个人履历。涉及 TikTok、Google 的产品规则需核对相关官方文档，不能将教学模型冒充公司内部算法。
