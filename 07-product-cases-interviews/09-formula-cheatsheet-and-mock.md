# 案例09｜广告业务公式速查与模拟试卷（题下即答案）

## 一、关键公式

| 问题 | 公式 | 必须核对 |
| --- | --- | --- |
| 实际广告收入与有效曝光 | R=I/1000×eCPM | I 与 R 的统计范围一致 |
| CTR | Clicks/Impressions | 事件计数口径 |
| CPM | Spend/Impressions×1000 | 币种与展示定义 |
| CPC | Spend/Clicks | 与报价 Bid 不同 |
| CPA | Spend/Conversions | 事件与归因窗口 |
| ROAS | Attributed Revenue/Spend | 不等于因果增量 ROAS |
| Frequency | Impressions/Reach | 时间窗与用户去重 |
| Delivery | Actual/Committed | 承诺与预测区别 |
| 实验绝对提升 | pT−pC | 百分点 |
| 实验相对提升 | (pT−pC)/pC | 基线必须非零 |
| 组合去重 Reach | A+B−Overlap | 两群体去重可比 |
| 新产品净增收入 | 新产品收入−内部预算迁移 | 还需处理其他替代 |
| 等效净贡献 | 净增收入−新增可归属成本 | 非完整净利润 |

## 二、模拟试卷

### 第1题：曝光与预算

某客户预计等效 CPM 为$12，媒体预算$120,000。在纯静态且预算全数按这个价格交付时，预计曝光多少？

**答案**：120,000/12×1000=**10,000,000 次曝光**。真实曝光仍受库存和交付影响。

### 第2题：去重触达

产品A触达200万人，B触达150万人，重叠40万人。组合独立触达？

**答案**：200+150−40=**310万人**，不能报告350万。

### 第3题：频次

曝光1200万次，独立触达300万人。平均频次是多少？

**答案**：1200/300=**4次/人**。不代表人人都看了4次。

### 第4题：量价互动

去年曝光1亿、等效eCPM=$10；今年曝光9000万、eCPM=$12。收入同比如何？

**答案**：去年$1,000,000，今年$1,080,000，增长**8%**。不能直接−10%+20%=+10%。

### 第5题：预算低消耗

每日预算$20,000，实际$8,000。消耗率？

**答案**：8,000/20,000=**40%**。这一比例本身不能定位根因。

### 第6题：转化效率

广告花费$15,000、点击30,000、转化750。实际 CPC、点击后 CVR、CPA？

**答案**：CPC=$0.50；CVR=750/30,000=**2.5%**；CPA=$15,000/750=**$20**。

### 第7题：品牌效果

实验组品牌记忆率32%，对照组24%。绝对与相对提升？

**答案**：**8个百分点、33.33%相对提升**。不能推导销售增加同样百分比。

### 第8题：新广告产品收入

新产品月收入$300,000，原产品预算迁移$180,000，新增成本$50,000。教学净增收入和新增贡献？

**答案**：净增收入$120,000；新增贡献**$70,000**，尚未考虑长期用户代价及更多机会成本。

### 第9题：实验数据

对照组10,000人转化2000，处理组10,000转化2200，绝对与相对效果？

**答案**：绝对+2个百分点，相对+10%；若独立二项假设成立，95%近似差异区间约[0.87,3.13]个百分点。

### 第10题：SRM

应50:50分流，实际A组12,000、B组8,000。应该直接分析收益吗？

**答案**：不应该。先排查分流和埋点；卡方统计量约800，严重偏离预期，实验可比性存疑。

### 第11题：对象粒度

1个Video被3个Ad复用、涉及2个广告账户。模型只命中该Video一次，能报告3个已确认违规广告吗？

**答案**：不能。按当前有效映射，最多说明1个素材级模型命中、3条关联Ad候选、2个账户关联，**确认违规与实际处置需要另有证据**。

### 第12题：综合业务题

“品牌广告收入下降20%”，请给出前三步。

**答案**：先统一财务和统计口径；再将收入拆成有效曝光与等效eCPM并检查产品结构；最后沿广告主预算需求、库存、交易、实际交付和计量链路寻找可验证的根因。不要直接说“提高广告负载”。
