## 一条业务主线

~~~mermaid
flowchart LR
 A["客户媒体预算"] --> B["平台预算份额"]
 B --> C["合格广告库存"]
 C --> D["匹配与交付"]
 D --> E["可确认广告收入"]
 E --> F["净贡献与客户效果"]
 F --> G["复投和长期流量"]
 G -. "长期反馈" .-> A
~~~

广告主预算≠平台确认收入；广告请求≠有效曝光；曝光上升≠净收益改善。每道计算须先限定分子、分母、时间窗和对象粒度，且不能将会计收入、广告主支出和统计归因混淆。

**推荐顺序**：01—03 建立恒等式，04—07 学习经济决策，08—09 做产品实验及业务题，10 用于复习。

文中数字均为虚构教学数据，不代表平台报价、财务或内部机制。公开平台功能请以官方帮助中心实际适用范围为准。
