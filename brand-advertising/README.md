# Brand Advertising Deep Dive｜品牌广告进阶专题

**Advertising & Monetization Learning · 专题研究**

本专题围绕国际化品牌广告商业产品的实际问题展开：**客户为什么投品牌广告、买什么广告产品、如何规划预算和触达、用什么证据证明品牌价值，以及平台如何改进产品并争取更多预算**。

与[广告基础知识](../01-advertising-fundamentals/README.md)不同，本专题不再从 CPM、CTR 的简单定义开始，而是分析完整品牌广告业务。与[广告经济学与变现](../02-advertising-economics-and-monetization/README.md)不同，本专题从**广告主、销售、品牌广告产品经理**三种视角审视一场品牌营销活动。

**注意**：这是用于学习的业务流程，不代表任何平台内部系统架构，也不意味着每个客户都会使用全部广告产品或品牌效果研究。

## 这五组概念必须分开

| 容易混淆 | 正确理解 |
| --- | --- |
| Marketing objective 与 buying type | 品牌知名度等营销目标，不等于 Auction、R&F 等购买机制 |
| Placement 与 ad format | 广告出现的位置不等于产品形式 |
| Format 与 creative | TopView 是广告产品形式，创意指内容表达与素材组合 |
| Reach、frequency 与 brand lift | 展示覆盖是过程，品牌认知增量是效果；不能互相替代 |
| Booked impressions 与 delivered impressions | 预订/预计交付与真实有效交付需要分别核查 |

## 使用说明

本文根据公开的 TikTok for Business / TikTok Ads Manager 帮助资料整理，主要核对截至 **2026-11-11** 可找到的官方说明。部分产品具有地区、资质、账户权限和可用库存限制，产品演进较快；本仓库不代表 TikTok 官方立场。文中所有数值规划、客户、商业目标与模型参数均为**虚构教学案例**，不是实际报价、行业平均或任何公司内部数据。
