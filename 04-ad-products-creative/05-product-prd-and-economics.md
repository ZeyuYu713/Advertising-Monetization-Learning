# 05｜广告产品全生命周期：从机会识别到 PRD、收入与实验

## 一、新广告产品要证明“不可替代的客户价值”

一个新样式往往不是因为“技术上可以放广告”就值得推出。应先研究客户现有营销任务是否无法被满足、平台是否存在合规的可售机会，以及产品是否会挤占已有库存和用户注意力。

例：某品牌需要在发布日触达尽可能多的独立消费者，但现有单个高可见产品覆盖不足。新产品可能尝试跨位置组合或更可预测的预订服务。具体方案要验证库存、重叠受众、交付成本和客户需求。

## 二、PRD 的八个核心板块

| 模块 | 必须回答 |
| --- | --- |
| 业务问题 | 谁受到影响、当前代价多大、可复用性如何？ |
| 目标与对象 | 哪类客户、场景、广告产品和地域？ |
| 用户体验 | 何时出现广告、怎样互动、如何保证清晰标识？ |
| 交易规则 | 支持哪种购买、计费、预算和资格？ |
| Creative 能力 | 支持哪些文件、授权和审核？ |
| 衡量与归因 | 曝光、Reach、有效观看、品牌/转化结果怎样计量？ |
| 工程与治理 | 延迟、回滚、权限、合规与数据质量要求 |
| 上线验收 | 采用率、净增收益、交付率、用户护栏 |

## 三、收入预测必须处理替代效应

教学示例：新产品预计月销售额 $500,000，其中 $260,000 是同一批客户从旧产品迁移来的预算；新增服务成本 $80,000。

简单净新增收入 $240,000，新增成本后的贡献 $160,000。这个估计尚未包含库存使用挤占了其他潜在交易，以及负载引起的长期用户变化。

不能把“新产品营业额 $500,000”视为“平台新增利润 $500,000”。

## 四、MVP 如何控制范围？

第一阶段可以限定少数市场、广告主资质、单一创意规格和明确可验证的交易模式，优先跑通从预订、素材审核、交付到报表的一整条链路。

不要为了“功能完整”同时加入跨市场预算自动分配、生成式视频素材、复杂动态定价和全部测量工具。先确认主要客户痛点是否存在，再逐步扩展。

## 五、如何设计实验

明确主指标为全平台可受影响收入的可信增量及合规有效交付；同时监控旧产品收入迁移、广告主效果、用户留存、负反馈、故障率。若市场/广告主预算互相影响，随机化单位应考虑跨组竞价干扰。

失败条件与回滚预案需要预先定义，不能实验结束后才决定哪些护栏重要。

## 六、面试追问

**问**：你会以“上线新广告样式后收入增长10%”证明成功吗？

**答**：先核查是否为同口径总收入、是否受到季节和流量变化影响、是否来自旧产品挪移；在合适实验中衡量净增量及体验代价。还要关注广告主是否重复购买，避免单次销售活动带来的短期幻象。
