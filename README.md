# Advertising & Monetization Learning

数字广告、商业化产品与流量策略知识库

本项目以<strong>广告业务逻辑 → 产品机制 → 数据分析 → 策略决策</strong>为主线，整理数字广告（Digital Advertising）、广告技术（AdTech）、商业化变现（Monetization）及产品策略（Product Strategy）的基础知识与案例。

**学习原则**：从业务问题出发，先说明概念与适用前提，再给出计算、具体场景、常见误区及产品经理视角；不把平台规则、个人推断和虚构练习数据混为一谈。内容主要为中文，保留常用英文术语。
