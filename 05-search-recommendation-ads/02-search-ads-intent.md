# 02｜TikTok 搜索广告：显式意图、关键词与广告产品

## 一、搜索广告为什么与信息流不同？

用户主动搜索“跑鞋测评”时，查询词提供了明确意图；在信息流随机浏览跑步视频时，用户可能根本没有购买意愿。搜索广告可以利用查询内容改善匹配，但查询并不能保证用户即将购买。

搜索广告产品要处理三层关系：Query（用户实际输入）→ Keyword（客户购买/定向词）→ Creative / Landing Page（广告内容与落地页）。不相关的广告即使高价也不应破坏基本搜索质量和广告政策。

## 二、TikTok 2026 年公开产品必须分开

| 公开产品 | 关键区别 | 提醒 |
| --- | --- | --- |
| Search Ads Campaign | 支持广告主设置关键词、预算和创意，在搜索结果场景投放 | 具体目标、国家和格式有限制 |
| Automatic Search Placement | 将适用信息流广告扩展到搜索位置，以自动方式匹配相关搜索 | 不是手动关键词 Search Ads 的同义词 |
| TopSearch | 特定市场与资格下，偏搜索高可见位置的品牌解决方案 | 2026-09 官方说明提供 Reach 目标等设置 |

官方资料：
- [About Search Ads Campaign](https://ads.tiktok.com/help/article/about-search-ads-campaign?lang=en)
- [Automatic Search Placement](https://ads.tiktok.com/resources/help/article/about-automatic-search-placement?lang=en)
- [How to set up a TopSearch campaign](https://ads.tiktok.com/resources/help/article/how-to-set-up-a-topsearch-campaign?lang=en)

TopSearch 不是 Google 搜索页面的“顶部竞价”概念直接搬过来，也不应假定所有账户都开放。搜索广告产品和购买规则有地区差异。

## 三、关键词与查询词区别

**Query / Search Term**：用户实际搜索内容，例如“跑鞋适合新手”。

**Keyword**：广告主在适用的 Search Ads Campaign 中设置的匹配对象，例如“跑步鞋”。

一个 Keyword 可能匹配多个相关查询，具体受 Broad / Phrase / Exact 等匹配设置和平台规则影响。不能认为用户一定完整输入了广告主设置的关键词。

## 四、品牌广告为什么也会买搜索？

品牌广告不只能靠开屏建立认知，还可能在用户主动寻找品牌、类别或产品时争取合适的搜索可见性。但品牌任务与转化任务需要分别衡量：品牌曝光质量、合适查询覆盖、搜索相关性、点击/转化与长期品牌效果。

## 五、搜索广告系统的典型约束

- 相关性：查询与广告素材及落地页是否一致；
- 准入：行业、地域、广告审查和品牌安全；
- 供需：某类查询流量是否足够、竞争是否过高；
- 预算：关键词/广告组/系列等适用配置；
- 测量：查询级数据可能因隐私、门槛和时延受限。

## 案例

用户搜索“免费跑步训练计划”，却大量看到高价鞋广告。即使广告短期 CTR 不低，也可能降低搜索满意度；应评估查询意图、广告相关性、负反馈与查询后用户行为，而非仅考虑出价。
