## 一张图看懂广告业务

广告主的营销目标与预算 → 平台提供可购买的广告库存与工具 → 按定向、档期、购买方式进行广告交付 → 用户看到品牌或产生互动 → 平台记录曝光与反馈 → 广告主评估效率及增量 → 决定复投、增投或调整策略。

需要特别注意：**投放完成不等于营销目标达成；高 CTR 不等于品牌认知提升；高预算也不等于一定花得出去。**

## 必须区分的五组概念

| 易混淆概念 | 正确区分 |
| --- | --- |
| Impression / Reach | 曝光是展示次数；触达是去重后的人数 |
| Campaign objective / KPI | Objective 是希望系统实现什么；KPI 是如何衡量结果 |
| Buying type / Billing event / Bidding strategy | 购买模式、实际计费触发事件、竞价时的控制方式是三个维度 |
| Placement / Format / Creative / Asset | 广告出现的位置、呈现方式、创意表达、具体素材 |
| Correlation / Incrementality | 看到广告的人购买更多，不自动说明广告造成了增量 |
